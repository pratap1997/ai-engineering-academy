# Module 013: References

1. **Sennrich, R., Haddow, B., & Birch, A. (2016)**. *Neural Machine Translation of Rare Words with Subword Units*. ACL.
   - **Provenance**: First paper to introduce Byte-Pair Encoding (BPE) for neural network NLP.

2. **Schuster, M., & Nakajima, K. (2012)**. *Japanese and Korean Voice Search*. IEEE ICASSP.
   - **Provenance**: Introduces the WordPiece tokenization scoring algorithm used by BERT.

3. **Kudo, T. (2018)**. *Subword Regularization: Improving Neural Network Translation Models with Multiple Subword Candidates*. ACL.
   - **Provenance**: Introduces the Unigram language model tokenization algorithm and SentencePiece framework.

4. **Radford, A. et al. (2019)**. *Language Models are Unsupervised Multitask Learners*. OpenAI.
   - **Provenance**: Introduces Byte-level BPE, eliminating `[UNK]` and enabling arbitrary string tokenization.
