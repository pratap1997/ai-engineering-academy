# Real Applications

## 1. InstructGPT and ChatGPT Alignment
OpenAI's InstructGPT (which led to ChatGPT) was the seminal application of PPO for alignment. They trained a Reward Model on human preferences, then optimized a GPT-3 base model using PPO.

## 2. Llama 3 Alignment Recipe
Meta's Llama 3 heavily utilized RLHF with both PPO and DPO. They used a combination of rejection sampling and DPO to iteratively refine the model's policy based on vast amounts of preference data.

## 3. Anthropic's Constitutional AI / RLAIF
Anthropic introduced Constitutional AI, where the preference data is generated by an AI (RLAIF - RL from AI Feedback). A helpful AI critique its own responses against a set of constitutional principles. The resulting AI-generated preference pairs are used to train the Reward Model (or directly via DPO).

## 4. LlamaFactory Preference Tuning
Open-source tools like LlamaFactory allow anyone to align models using DPO, ORPO, or KTO with just a few commands, democratizing the preference alignment process.
