# Real Applications

Tree of Thoughts and MCTS are actively used in state-of-the-art AI reasoning systems:
1. **OpenAI o1 / Q* Reasoning Architectures**: Advanced LLMs use search techniques during inference to explore multiple reasoning paths before answering.
2. **Mathematical Reasoning**: Tree search enables agents to backtrack from algebraic dead-ends.
3. **AlphaZero MCTS Decision Making**: The original breakthrough that mastered Go and Chess by combining neural policies with MCTS.
4. **Automated Theorem Proving**: Navigating the massive branching factor of logical proofs requires MCTS combined with LLM heuristics.
