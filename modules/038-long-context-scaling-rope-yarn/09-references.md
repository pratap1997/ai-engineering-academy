# 09 - References

1. **RoFormer (Su et al., 2021)**: "RoFormer: Enhanced Transformer with Rotary Position Embedding". Introduces the mathematical foundation of RoPE.
2. **Position Interpolation (Chen et al., 2023)**: "Extending Context Window of Large Language Models via Positional Interpolation". The first paper to propose Linear RoPE scaling.
3. **YaRN (Peng et al., 2023)**: "YaRN: Yet Another RoPE Extrapolation Method". Details the advanced ramp function and temperature scaling mechanisms for optimal context extension.
4. **vLLM Documentation**: "Chunked Prefill". Explains the engineering challenges of handling massive prompts and how chunking the prefill phase optimizes throughput.
