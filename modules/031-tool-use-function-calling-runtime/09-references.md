# References

1.  **Schick et al. (2023). Toolformer: Language Models Can Teach Themselves to Use Tools.**
    *Context:* Foundational paper demonstrating how LLMs can be trained to generate API calls within their text outputs.

2.  **E2B Sandbox Architecture Documentation.**
    *Context:* Real-world reference for how cloud-based AI agents are securely sandboxed using microVMs.
    *URL:* https://e2b.dev/docs

3.  **OWASP Top 10 for Large Language Model Applications.**
    *Context:* Specifically addresses LLM02: Insecure Output Handling and LLM08: Excessive Agency, which Tool Runtimes aim to mitigate.
    *URL:* https://owasp.org/www-project-top-10-for-large-language-model-applications/

4.  **Python AST Module Documentation.**
    *Context:* Standard library documentation for building static analysis tools to ensure safe code execution.
    *URL:* https://docs.python.org/3/library/ast.html
