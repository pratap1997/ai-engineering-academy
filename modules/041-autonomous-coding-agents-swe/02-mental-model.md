# Mental Model: The Junior Developer at the Terminal

## The Metaphor
Think of a SWE agent as a junior developer starting at a company. They don't know the entire codebase by heart. Instead, they:
1. **Read** specific files to build context.
2. **Edit** a file to implement a fix.
3. **Run** the test suite to verify.
4. **Fix** any syntax or logical errors based on test feedback.

This iterative feedback loop replaces the need for a 'god-like' single prompt that writes the entire program correctly on the first try.
