# 03 - Mathematics: Formalizing Agentic Loops

To move beyond intuition and rigorously build agentic systems, we must formalize the components of the loop.

## The POMDP Formulation
An agent interacting with an environment through tools and observations can be formally modeled as a Partially Observable Markov Decision Process (POMDP). A POMDP is defined by the tuple $(\mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R}, \Omega, \mathcal{O}, \gamma)$:

- $\mathcal{S}$: The set of hidden environment states.
- $\mathcal{A}$: The set of possible actions (tool calls or final answers).
- $\mathcal{T}(s' | s, a)$: The transition probability of moving to state $s'$ given state $s$ and action $a$.
- $\mathcal{R}(s, a)$: The reward function.
- $\Omega$: The set of possible observations (tool execution results).
- $\mathcal{O}(o | s', a)$: The observation probability.
- $\gamma \in [0, 1]$: The discount factor.

Because the agent cannot directly see the true state $\mathcal{S}$ of the world (e.g., the exact schema of a database until queried), it must maintain a belief state or history of observations to inform its policy $\pi$.

## ReAct Formal Definition
In the ReAct framework, the agent's interaction trajectory $\tau$ interleaves observations, thoughts, and actions. Let $c$ be the initial context or user query. The trajectory at step $i$ is:

$$ \tau_i = (c, t_1, a_1, o_1, t_2, a_2, o_2, \dots, t_i, a_i, o_i) $$

Where:
- $o_i \in \Omega$ represents an observation from the environment.
- $t_i \in \mathcal{L}$ represents a thought generated by the language model (where $\mathcal{L}$ is the space of natural language strings).
- $a_i \in \mathcal{A}$ represents an action taken by the agent.

The language model acts as the policy, parameterized by weights $\theta$, estimating the probability of the next thought or action given the trajectory history:

$$ P_\theta(t_i | \tau_{i-1}) \quad \text{and} \quad P_\theta(a_i | \tau_{i-1}, t_i) $$

## Tool Use Probability
Let $\mathcal{T} = \{T_1, T_2, \dots, T_k\}$ be the tool registry. An action $a_i$ consists of selecting a tool $T_j \in \mathcal{T}$ and generating the corresponding arguments $x$. The probability of executing a specific tool call is decomposed as:

$$ P(a_i | s, \mathcal{T}) = P(T_j | s) \cdot P(x | s, T_j) $$

Where $s$ is the current state (or trajectory context $\tau_{i-1}, t_i$). The model must first correctly classify which tool is appropriate (a categorical distribution over $k$ tools) and then accurately generate the arguments conditioned on the chosen tool schema.

## Bandit Problem Formulation for Tool Selection
In autonomous exploration, selecting the right tool can be framed as a Multi-Armed Bandit problem. We wish to maximize cumulative reward by balancing exploitation (using tools known to work for similar queries) and exploration (trying new tools). The Upper Confidence Bound (UCB1) algorithm selects action $a$ to maximize:

$$ \text{UCB}(a) = Q(a) + c \sqrt{\frac{\ln N}{n(a)}} $$

Where:
- $Q(a)$ is the estimated average value of taking action $a$ (e.g., success rate of a tool).
- $N$ is the total number of actions taken so far.
- $n(a)$ is the number of times action $a$ has been selected.
- $c$ is an exploration parameter.

## Planning as Tree Search
In frameworks like Tree of Thoughts (ToT), planning is formalized as a search over a tree where nodes represent partial solutions (thoughts/states) $s$. Let $V(s)$ be the value function estimating the likelihood that state $s$ leads to a successful outcome. 

When utilizing Monte Carlo Tree Search (MCTS) for planning, the agent balances traversing deep into promising paths and exploring new branches. The selection of a child node $s'$ from parent $s$ uses the UCB formula applied to tree search (UCT):

$$ \text{UCT}(s') = \frac{W(s')}{N(s')} + c \sqrt{\frac{\ln N(s)}{N(s')}} $$

Where $W(s')$ is the sum of values (or simulation wins) for node $s'$, and $N(s')$ is the number of visits to node $s'$. 

## Bellman Equation in Agentic Contexts
If we treat the agent's loop as a reinforcement learning problem, the optimal value function $V^*(s)$ of a state follows the Bellman optimality equation:

$$ V^*(s) = \max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{T}(s' | s, a) V^*(s') \right] $$

While LLMs are typically trained via supervised learning (next-token prediction), modern alignment techniques like RLHF (Reinforcement Learning from Human Feedback) implicitly optimize a reward function approximating this equation, training the agent to select actions $a$ that maximize long-term task completion rather than just immediate token likelihood.
