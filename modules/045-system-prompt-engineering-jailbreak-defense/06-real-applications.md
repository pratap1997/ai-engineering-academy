# Real Applications

## Leaked System Prompts
Security researchers actively study leaked system prompts (e.g., `asgeirtj/system_prompts_leaks`) to understand how major companies structure their instructions and what vulnerabilities exist.

## Anthropic Claude System Instructions
Anthropic often employs extensive XML-based structures to delineate rules, tool descriptions, and user inputs, relying heavily on the model's instruction-following fine-tuning and strict formatting.

## NeMo Guardrails
NVIDIA's open-source framework for building safe, secure LLM conversational systems by defining programmable guardrails.
